# @cuelith/panel

Helpers for Cuelith plugin panels: call the plugin commands and follow the show state from an isolated panel.

Part of [Cuelith](https://github.com/Cuelith/cuelith-core), free live-projection software. How to write a plugin: the [Author guide](https://github.com/Cuelith/.github/blob/main/AUTHOR-GUIDE.md).
